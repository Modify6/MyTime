## 1. 产品概述

### 1.1 一句话定位
**柳比歇夫时间统计法的数字化工具**：如实记录每件事的"纯时间"，自动沉淀为统计与复盘，让历史用时反哺未来决策。

### 1.2 目标用户
- 柳比歇夫法的实践者/想入门的人（核心）
- 想要"时间去哪了"真实答案、而非打卡打卡形式的人
- 多设备（手机+电脑）使用、在意数据自有与隐私的用户

### 1.3 核心价值主张
1. **串行记账**：同一时刻只记录一件事——这是方法的纪律，产品用调度机制保证它可执行
2. **统计即反馈**：日/周/月/复盘四层视角，把记录变成对预估力的校准
3. **本地优先**：断网可用，数据在本机；自托管服务器做同步与快照，没有第三方看你的时间
4. **历史反哺决策**：模板平均用时、目标进度节奏、预估 vs 实际偏差——开新事件前先看历史

### 1.4 非目标（明确不做）
- 不做团队协作/共享（个人工具）
- 不做自动时间追踪（屏幕监测等）——如实记录本身是方法的一部分
- 不做社交/排行榜——避免把严肃记录变成表演

## 2. 核心用户旅程

```
首次进入 → 默认分类播种 → 快捷球一键打卡 → 时间线看到第一段记录
    ↓（形成习惯）
每日：打卡 → 空白补录提醒 → 时间轴核对 → 当日结算通知
    ↓（每周/月）
复盘：计划预估 vs 实际 → 时间流向 vs 上期 → 挂起原因趋势 → 目标/预算进度
    ↓（长期）
模板沉淀重复事件组 → 历史用时反哺新计划预估 → 时间结构按意愿演进
```

## 3. 功能规格

### 3.1 打卡计时（今日页）

| 功能 | 规格 |
|---|---|
| 快捷球 | 按历史习惯（频次+近时性）生成 6 个环绕球，点球即开始；中央「打卡」进入完整表单（标题/分类/目标/预估） |
| 智能推荐 | 面板内「为你推荐」按时段+习惯分析此刻适合做什么 |
| 串行调度 | 已有计时中再点新事件 → HandoffDialog：挂起当前再开始（多段执行留痕） |
| 进行中面板 | 分类色 SVG 圆环（弧=今日该分类已投入占比，首段最小 3% 弧）+ 环心白色计时 + ghost 钮（放弃/挂起/备注）+ 全宽「结束打卡」 |
| 结束反馈 | 落账 toast 带预估偏差%（有关联预估时）；挂起必须填原因（复盘页统计用） |
| 多设备冲突 | 「其他进行中的计时」列出他端开始的计时，可点击处理 |

### 3.2 记录管理（记录页）

| 功能 | 规格 |
|---|---|
| 三视图 | 按日分组列表 / 月历（格子深浅=投入量，点日展开明细）/ 单日时间轴（竖向标尺） |
| 时间轴 | 自适应时段范围、泳道并排呈现重叠、"现在"线、点色块编辑；**重叠警示**（琥珀 N 段+品牌蓝"可修正"） |
| 空白补录 | 今日页空闲态检测 ≥1h 空白 → 提示卡一键预填；时间轴弹层「最近空档 · 点此补录」 |
| 编辑 | 改时间/分类/目标/备注/预估；**从中间拆成两条**（两件事连着记了）；软删墓碑多端一致 |
| 补录 | 手动补任意过去时段（EventEditor 草稿模式支持预填起止） |

### 3.3 统计（统计页，日/周/月/复盘四分段 + 前后翻期）

| 图表 | 规格 |
|---|---|
| 概览卡 | 合计纯时间/记录条数/较上期%（▲琥珀 ▼绿） |
| 目标与预算 | 每周/每月目标进度（正常蓝/落后琥珀/达成绿 + "时间已过 x%"节奏对照）；分类每周预算（接近琥珀/超出红） |
| 趋势 | 近 30 天本期蓝实线面积 + **上一个 30 天灰虚线**同轴对比 |
| 时段分布 | 近 30 天 **工作日 vs 周末** 0–23 时日均双曲线（求平均避免样本量差异） |
| 分类小趋势 | Top 4 分类 30 天 SVG sparkline + 环比上一 30 天（▲▼%/新增） |
| 专注热力图 | 近半年 GitHub 式，流式铺满不滚动；**连续记录 streak**（今天没记不断档）；点格跳当天 |
| 分类占比 | 环形图中心总时长 + 图例（色点/名称/占比/时长） |
| Top 事项 | 横条排行（时长+次数） |
| 柳比歇夫报告 | 当日纯文字结算（可一键复制） |
| 色带 | 日模式 24h 分类色带（泳道防重叠，进行中画到当前时刻） |

### 3.4 复盘（统计页第四分段，按周/按月粒度）

| 功能 | 规格 |
|---|---|
| 计划 vs 实际 | 期内有投入的计划逐条对比预估（未启动/无预估对照/偏差%着色） |
| 时间流向 | 本期 vs 上期两条全宽分类色堆叠条 + 分类明细行（数值+增减着色） |
| 挂起原因 | 期内挂起原因分布条形 + 上期对照 |

### 3.5 计划系统

| 功能 | 规格 |
|---|---|
| 两类计划 | 预排（提前编排）/ 临时（随手记），分区展示：执行中/挂起中/提前规划/临时（等待执行）/已完成已取消 |
| 状态机 | waiting → active → paused ⇄ active → done/cancelled；非法迁移被拒绝（CAN_TRANSITION） |
| 执行履历 | planLogs 记录启动/挂起(原因)/恢复/完成/取消，详情页展示履历时间线与统计 |
| 多段执行 | 挂起→恢复多次，累计投入累计计算 |
| 删除 | 等待中可删；完成/取消走归档；**时间数据永远保留**（删除只删计划记录） |
| 模板 | 事件组模板（如"一次出差的流程"）一键实例化整组计划；支持从某天真实记录导入为模板项；同模板多次执行自动统计平均/最多/最少用时 |

### 3.6 目标与预算

| 功能 | 规格 |
|---|---|
| 目标 | 挂"大事"（goalId），可选周期：**累计 / 每周 / 每月**（targetType） |
| 进度 | 统计页五模式统一卡：日模式显示本周+本月，周/月/复盘跟随所在周期；三态色+节奏对照（时间已过 x%，落后 >5% 提示） |
| 预算 | 分类可设每周上限（budgetHours）；进度行三态（正常/接近琥珀/超出红+"已超出 X"） |
| 目标页 | 本期口径显示投入（本周投入/本月投入/累计投入）+ 平均单次 |

### 3.7 同步与备份（自托管）

| 功能 | 规格 |
|---|---|
| 架构 | 本地优先：Dexie(IndexedDB) + outbox 待推队列 + LWW(updatedAt) + serverRev 增量游标；Fastify + node:sqlite 单文件服务端 |
| 触发 | 登录后每 30s/联网恢复/回前台/本地写入后 3s 防抖自动同步 |
| 参考数据对账 | 每次同步成功拉服务端分类+目标 LWW 采纳——本地参考表丢失/游标过高时一次同步自愈（历史"未分类/目标丢失"的根治） |
| 快照 | 服务器每日自动快照（保留 30 份）；设置页立即备份/下载（APK 走 Filesystem+系统分享）；PC 端 `快照拉取.bat`/`snapshot-pull.mjs` 拉取到本地 `backups-local/`（异地化，可挂任务计划） |
| 备份修复 | 服务端快照 POST 空 body 400 已修复；自动每日备份默认可开 |

### 3.8 系统与原生

| 功能 | 规格 |
|---|---|
| 多端 | PWA（Service Worker 预缓存）+ Android APK（Capacitor，本地工具链一键打包 `apk.bat`） |
| 每日结算通知 | APK 本地通知固定时间提醒（默认 21:30，可改），点开直达统计页；与打卡提醒（原生 ReminderNative）并存 |
| 深色模式 | 跟随系统，CSS 变量双套；ECharts 轴/网格/提示框色统一走 chartPalette |
| 帮助体系 | 每页「📖说明」胶囊 → 小节化弹层（品牌徽章/横条小节/正文主色/**强调词**品牌色）；文案集中 `feature-notes.js` |
| 数据维护 | 墓碑统计 + 90 天前清理（近期墓碑保留防多端回填，清理后自动对账） |
| 运行日志 | 环形缓冲 500 条，可复制/导出/上传服务端（排障用） |
| 版本迭代 | CHANGELOG 驱动的版本史弹层；发版流水线 `release.mjs`（测试→版本贯通→CHANGELOG→构建→tag→推送重试） |
| Widget/通知 | 通知栏常驻计时（原生插件）+ 桌面小组件深链（widget/start / widget/stop） |

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 个人量级（万级事件）内存过滤足够；ECharts 按需加载 chunk；首屏静态导入避免原生 WebView 动态 import 失效 |
| 离线 | 全功能可用（除同步/快照/日志上传）；Service Worker 预缓存 |
| 隐私 | 自托管，无第三方统计/上报；数据可随时导出 JSON/CSV |
| 一致性 | 软删墓碑 + LWW；参考数据对账自愈；墓碑 90 天可清理（离线超 90 天的设备回来可能把已删数据推回——已知权衡） |
| 兼容 | 移动竖屏优先（390 宽基准）；现代浏览器 + Android WebView |
| 质量 | 纯函数聚合层 vitest 单测（68 例）；Playwright E2E（10 场景，隔离库 3139 专口）；pre-commit 跑单测 |

## 5. 信息架构

```
底部 Tab：今日 ｜ 记录 ｜ 统计 ｜ 计划 ｜ 目标 ｜ 设置
├ 今日：计时中面板/快捷球+推荐/空白补录/时间线/分类小计
├ 记录：列表·月历·时间轴 + 编辑器/补录
├ 统计：日·周·月·复盘 四分段图表群
├ 计划：计划Tab（分区列表）/ 模板Tab（模板管理+从记录导入）
│   └ 计划详情：执行统计 + 履历时间线
├ 目标：目标卡（进度）/ 归档
│   └ 目标详情：累计投入/次数/平均单次
└ 设置：同步配置/分类管理/数据备份/数据维护/提醒/日志/关于(版本史)
```

## 6. 数据模型（概览）

| 表 | 关键字段 | 说明 |
|---|---|---|
| events | startAt/endAt/categoryId/goalId/planId/estimateMs/note | 核心：纯时间记录（endAt null=进行中） |
| categories | name/color/sort/budgetHours | 分类（含每周预算） |
| goals | name/color/targetType(target/weekly/monthly)/targetHours/archived | 目标（大事） |
| plans | kind(planned/temp)/status/pauseReason/estimateMs/templateId/instanceId | 计划（模板实例同 instanceId 成组） |
| planLogs | planId/action/reason/at | 执行履历 |
| templates | items(JSON) | 事件组模板 |
| outbox/meta | — | 待推队列 / 同步游标与本地配置 |

同步约定：所有业务表带 updatedAt/deleted；服务端 serverRev 为增量游标；LWW 整行覆盖。
