# 双机无缝迁移指南（项目 + AI 对话记录）

场景：把 MyTime 项目**连同 ZCode 的记忆与全部对话记录**搬到另一台电脑工作，之后再搬回来。
两条硬规则：**代码靠 git 往返**；**git 装不下的东西靠导出包私有通道往返**。

## 一图看懂搬什么

| 内容 | 载体 | 怎么走 |
|---|---|---|
| 项目代码与全部标签 | git | `push` / `pull`（GitHub） |
| git 装不下的：部署私钥、deploy/config、本地 server 数据 | 导出包 `secrets/`、`server-data/` | U 盘/加密网盘（**绝不入库**） |
| AI 记忆（每会话自动加载） | `~/.zcode/cli/memories/projects/mytime-*` | 导出包 |
| 全部对话记录 | `~/.zcode/cli/db/db.sqlite*` | 导出包 |
| VPS 上的线上数据 | 不用迁 | 本来就在服务器上，两台电脑共用 |

## 第 1 步：离开这台电脑前

```bash
# 1. 代码全部上云（工作树必须干净——有半成品就先 commit，哪怕是 WIP）
git add -A && git commit -m "wip: 迁移前快照" && git push

# 2. 打包 git 装不下的部分（默认输出到仓库上级目录，64MB 左右）
node scripts/migrate-export.mjs
```

把输出的 `mytime-migrate-export/` 整个拷到 U 盘/加密网盘，**到新机后删除中转副本**（里面有私钥和对话记录）。

## 第 2 步：新电脑到达后

```bash
# 0. 前置：装 Node 22+ 与 Git（打包 APK 才需要 Android Studio）
# 1. 克隆项目到任意目录，进入项目根目录
git clone https://github.com/Modify6/MyTime.git
cd MyTime

# 2. 一键恢复（私钥/配置/本地数据/记忆/对话记录，含 Windows ACL 收紧）
node scripts/migrate-import.mjs <U盘里的 mytime-migrate-export 目录>

# 3. 环境收尾（脚本末尾会打印同样的清单）
npm install && npm install --prefix server && npm install --prefix web
git config core.hooksPath .githooks
ssh mytime "echo ok"      # 验证服务器连通（用 Windows OpenSSH，见 deploy/README.md）
npm --prefix web test     # 39 例应全过
```

**记忆键的注意点**：ZCode 的记忆目录名（`mytime-<哈希>`）由项目路径派生。
- 新机把项目放在**同名路径**（如都在 `E:\study\zi\MyTime`）→ 自动匹配，无感
- 路径不同 → 打开一次 ZCode 后它会生成新键目录，把导出的 memory 文件夹内容拷进新键目录即可（导入脚本会提示）

**对话记录**：恢复 db 后新机的 ZCode 能看到全部历史会话并继续 resume。恢复/导出前**先关掉 ZCode**（数据库文件被占用），关不掉就重跑一次导入。

## 第 3 步：在新电脑上日常工作

和平时完全一样——ZCode 自动加载记忆，对话接着聊；代码改动照常走 `release.mjs` 发版。

唯一纪律：**不要两台机器同时改代码**。离开任何一台前 `git push`，到达另一台先 `git pull`。

## 第 4 步：搬回原来的电脑

完全对称：

```bash
# 新电脑上：
git add -A && git commit -m "wip: 回迁前快照" && git push
node scripts/migrate-export.mjs        # 打包这段时间新产生的记忆/对话

# 原电脑上：
git pull
node scripts/migrate-import.mjs <U盘里的导出目录>
```

导入脚本对已存在的会话库会**先备份再覆盖**（`~/.zcode/backup-migrate-时间戳/`），原电脑迁移前没同步进库的对话不会丢。

## 常见坑

- **ZCode 没关就导出/导入**：WAL 未合并/文件被锁。关掉重跑即可，脚本会检测并提示
- **忘了同步 `deploy/config`**：表现为 `ssh mytime` 正常但 `upload.sh` 报 SERVER_HOST 未设置——它是 gitignore 的，靠导出包走
- **VPS 不用搬**：线上数据/快照都在服务器上，两台电脑只是它的两个客户端
- **APK 打包工具链**（JDK/Android SDK）不随迁移走：新机需要打包时按 `apk.bat` 的提示装 Android Studio，或直接用 CI Release 的 APK
